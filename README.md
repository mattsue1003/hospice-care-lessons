# 好好說再見：安寧緩和五堂課

林口社區大學中高齡生命教育講座的「影片教學法」互動網頁。五支 9:16 小麻雀短片，一課一個主題，每課照「想一想 → 看影片 → 問到底 → 真實案例 → 聊一聊 → 帶回家」六步走。

**線上上課：** https://mattsue1003.github.io/hospice-care-lessons/

## 每課流程

上方標籤切換五堂課，每課六步，用「下一步」往下走：

1. **想一想**：開場投票，沒有對錯
2. **看影片**：小麻雀短片，中途 3 次停格提問
3. **問到底**：7～9 個大家最常問的細節（要不要錢、要多久、獨居怎麼辦、可以反悔嗎……），先猜再揭曉
4. **真實案例**：新聞時事、國際、藝人與名人案例，每則五步：情境 → 你會怎麼做 → 猜猜看 → 後來呢 → 學到什麼
5. **聊一聊**：小組討論題＋講師提示
6. **帶回家**：本課重點＋回頭看開場的選擇＋一件今天就能做的事

五堂課上完，最後寫「我的心願卡」，變成一封給家人的信。另有資源與專線、講師使用（90 分鐘流程）、投影用大字模式。作答與心願卡只存在學員自己的瀏覽器。
