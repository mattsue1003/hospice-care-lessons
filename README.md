# 好好說再見：安寧緩和五堂課

林口社區大學中高齡生命教育講座的「影片教學法」互動網頁。五支 9:16 小麻雀短片，一課一個主題，看完影片再用「問到底」把細節一題一題問清楚，新聞與名人案例則像說故事一樣邊投票邊猜。

**線上上課：** https://mattsue1003.github.io/hospice-care-lessons/

## 每課流程

先想想（暖身投票）→ 看影片（中途 3 次停格提問）→ 重點整理 → 問到底（7～9 題，先猜再揭曉）→ 一起討論 → 帶回家做一件事

## 其他區塊

- **案例互動**：16 則新聞時事、國際、藝人與名人案例，每則五步：情境 → 你會怎麼做 → 猜猜看 → 後來呢 → 學到什麼
- **課前・課後小測**：8 題是非，比較前後成績
- **我的心願卡**：勾選後變成一封給家人的信
- **資源與專線**、**講師使用**（90 分鐘流程與帶領提醒）、投影用大字模式

作答與心願卡只存在學員自己的瀏覽器。
